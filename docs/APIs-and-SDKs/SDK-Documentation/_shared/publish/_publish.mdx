Call `publish()` before page navigations, server responses, or any point where
the process might exit before the SDK's auto-flush fires. This ensures exposure
and goal data is sent to the collector before the context is lost.

<TabItem value="python" label="Python3">

Python also provides `publish_async()` for non-blocking use.

Without an explicit `publish()`, the Python SDK sends queued events after
`ContextConfig.publish_delay` **seconds**, which defaults to **50 seconds**. Set a
smaller value (in seconds) to publish sooner, or `0` to publish immediately.

Before the process exits, call `close()` instead of `publish()`. `close()` also stops
automatic refresh, whose timer otherwise keeps the Python process running.
